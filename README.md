# Order Refund Flow

A staff refund workflow built with Next.js, TypeScript, Tailwind CSS, and Radix UI for issuing partial or full refunds on completed food-and-drink orders.

**Live demo:** _[Add your Vercel or GitHub Pages URL here after deploying]_

---

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Scripts

```bash
npm run test:run   # Run unit tests once (Vitest)
npm test           # Run Vitest in watch mode
npm run build      # Production build
npm run preview    # Serve the production build
```
